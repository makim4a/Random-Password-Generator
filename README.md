Название темы: Random Password Generator

Описание

Random Password Generator — это графическое приложение для генерации надёжных случайных паролей с настраиваемыми параметрами. Программа позволяет:

выбирать длину пароля (от 8 до 32 символов);

включать/исключать различные типы символов (цифры, буквы, специальные символы);

копировать сгенерированный пароль в буфер обмена;

просматривать историю сгенерированных паролей;

сохранять историю паролей между запусками программы.

Технические детали:

язык программирования: Python;

библиотека для GUI: tkinter;

хранение истории: JSON‑файл.
